# RestartApp

A SwiftUI iOS application showcasing interactive onboarding, fluid animations, and gesture-driven UI components.

## Features

- Interactive onboarding flow with draggable slider
- Dynamic drag gestures and real-time parallax tilt effects
- Custom audio effects and haptic feedback
- Persistent onboarding state using AppStorage
- Smooth transitions and repeating SwiftUI animations

## Tech Stack

- Swift
- SwiftUI
- AVFoundation
- UIKit (Haptics)
